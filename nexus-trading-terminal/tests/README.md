# Tests

Tests live next to the code they cover:

* `services/<package>/tests` — Python unit and integration tests (`npm run test:api`)
* `apps/web/tests/unit` — web unit tests (`npm run test:web`)
* `apps/web/tests/e2e` — Playwright end-to-end tests (`npm run build && npm run test:e2e`)

See [docs/TESTING.md](../docs/TESTING.md).
